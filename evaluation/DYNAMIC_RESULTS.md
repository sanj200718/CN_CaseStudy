# Dynamic Simulator Benchmark (Preliminary)

Generated by `run_dynamic_experiments_state_cycle.py` using 30 paired runs per method and scenario. This is still a simulated graph experiment, not a Mininet packet-level test.

| Scenario | Dijkstra mean route cost | DQN mean route cost | DQN cost change vs. Dijkstra | Destination success for both |
|---|---:|---:|---:|---:|
| Dynamic delay spike | 63.6217 | 65.8303 | +3.47% | 100% |
| Dynamic link failure | 73.8030 | 76.1376 | +3.16% | 100% |
| Gradual delay drift | 39.7640 | 45.4700 | +14.35% | 100% |

Positive cost change means DQN had higher cost. Dijkstra had lower mean simulated route cost in all three scenarios. Both methods reached the destination in all 90 runs each. These observations do not prove or disprove ML's performance in a live SDN network.

The dynamic evaluator passes the DQN route history to inference. It allows a previously visited node only when network state has changed, and flags a cycle when the same node, graph-edge signature, and delay-matrix signature recur. Dijkstra recomputes a shortest path for the current network snapshot.

Regenerate with:

```bash
python evaluation/run_dynamic_experiments_state_cycle.py --runs 30
```

CSV tables and graphs are saved in `evaluation/results_dynamic_state_cycle/`.
